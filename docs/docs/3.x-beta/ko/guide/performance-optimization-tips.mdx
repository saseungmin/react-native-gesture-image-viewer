# 성능 최적화 팁

#### 대용량 이미지의 경우 [`expo-image`](https://docs.expo.dev/versions/latest/sdk/image/)나 [`FastImage`](https://github.com/DylanVann/react-native-fast-image) 사용을 권장합니다.

```tsx
import { useState } from 'react';
import { Modal } from 'react-native';
import { GestureViewer } from 'react-native-gesture-image-viewer';
import { Image } from 'expo-image'; // [!code highlight]

function renderImage(imageUrl: string) {
  return <Image source={{ uri: imageUrl }} style={{ width: '100%', height: '100%' }} contentFit="contain" />; // [!code highlight]
}

function App() {
  const images = [...];
  const [visible, setVisible] = useState(false);

  return (
    <Modal visible={visible} onRequestClose={() => setVisible(false)}>
      <GestureViewer
        data={images}
        renderItem={renderImage}
        onDismiss={() => setVisible(false)}
      />
    </Modal>
  );
}
```

이미지 데이터에 원본 치수가 이미 있다면 `getItemDimensions`로 전달하세요. 치수를 로드 이후에만 알 수 있다면 `renderItem`에서 `setItemDimensions`로 보고하고, 같은 논리 아이템이 같은 slot에서 다른 객체로 다시 만들어질 수 있다면 그 runtime 경로와 함께 `getItemKey`를 사용해 치수가 그 slot에 유지되도록 하세요. 추가 레이아웃 측정 없이 `contain` 이미지의 줌/팬 범위를 정확하게 맞출 수 있습니다.

#### 인접 페이지를 더 많이 마운트해야 하는 경우가 아니라면 render window를 작게 유지하세요.

기본 `windowSize`는 `3`이며 이전, 현재, 다음 아이템을 마운트합니다. 더 큰 window는 인접 페이지를 더 빨리 보여줄 수 있지만 렌더링, 메모리, 이미지 디코딩 작업도 늘어납니다. 라이브러리는 `windowSize`에 하드 최대값을 두지 않으므로, 큰 값을 선택하는 것은 명시적인 성능 tradeoff입니다.

```tsx
import { useState } from 'react';
import { Image, Modal } from 'react-native';
import { GestureViewer } from 'react-native-gesture-image-viewer';

function renderImage(imageUrl: string) {
  return <Image source={{ uri: imageUrl }} style={{ width: '100%', height: '100%' }} resizeMode="contain" />;
}

function App() {
  const images = [...];
  const [visible, setVisible] = useState(false);

  return (
    <Modal visible={visible} onRequestClose={() => setVisible(false)}>
      <GestureViewer
        data={images}
        renderItem={renderImage}
        windowSize={3} // [!code highlight]
        onDismiss={() => setVisible(false)}
      />
    </Modal>
  );
}
```
